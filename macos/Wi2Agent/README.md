# Wi2Agent

Wi2のゲストコード取得・更新通知・残り時間の表示を行うmacOSアプリです。ゲストコードの入力と再ログインは手動です。Wi2側の利用期限を延長する機能ではありません。

## インストール

Appleシリコン搭載MacとmacOS 14以降に対応します。Releasesから`Wi2Agent-macos-arm64.pkg`をダウンロードします。インストーラーは未署名・未公証のため、開く前にターミナルで次を実行してください。

```bash
xattr -d com.apple.quarantine ~/Downloads/Wi2Agent-macos-arm64.pkg
```

保存先を変更した場合は、コマンドのパスも変更します。ダウンロードした`.pkg`をダブルクリックし、画面に従ってインストールしてください。`/Applications/Wi2Agent.app`へ配置されます。起動中のWi2Agentは、インストール前にメニューバーから終了してください。

ソースからインストールする場合はSwift 6.2以降が必要です。起動中のWi2Agentを終了してから、リポジトリのルートで実行します。

```bash
pnpm install:macos
```

ad-hoc署名した`/Applications/Wi2Agent.app`をインストールして起動します。`pnpm build:macos`でアプリと`.pkg`インストーラーを`macos/Wi2Agent/.build`へ生成します。

## 新しく接続する場合

1. 初回起動時に通知の許可を求めます。許可済みでもバナーが無効な場合や、以前に拒否した場合は、通知設定を開く確認が表示されます。macOSは拒否後の許可ダイアログを再表示しないため、システム設定でWi2Agentの通知とバナーを有効にしてください。
2. `API設定`で自分のWorkerの`/code`URLとAPIトークンを保存します。未設定の場合は自動で設定画面を開きます。URLは端末の設定へ、トークンはKeychainへ保存します。
3. インターネットへ接続できる回線で`コードを取得して接続`を押します。
4. 自動でWi2へ切り替わります。切り替え処理の終了を待たずに`ログイン完了`を押せます。Wi2のキャプティブポータルで`ゲスト`→`ゲストログイン`を開き、表示されたコードを入力します。
5. `ログイン画面を開く`でアプリ専用のWebKitウインドウを開きます。インターネットに接続できたら、メイン画面またはログインウインドウの`ログイン完了`を押します。この時点から10分のタイマーが始まり、次回のコードを取得します。
通知設定はウインドウ上部のベルボタンから開けます。通知に失敗した場合は通知済みと記録せず、15秒後に再試行します。

## 接続済みのWi2を引き継ぐ場合

`接続済みのWi2を引き継ぐ`を開き、ログインからの経過分数を指定して`引き継いで開始`を押します。Wi-Fiを切り替えずにタイマーを開始し、次回のコードを取得します。残り時間は入力した時刻を基準にした目安です。

## 接続を更新する場合

1. ログイン直後に次回のコードを取得します。失敗した場合、利用時間内は15秒間隔で再試行します。同じコードが返った場合も再試行します。
2. 利用期限が切れた時点で通知し、ログイン用の独立ウインドウを自動で開きます。コードはアプリとログインウインドウで確認・コピーできます。
3. 利用期限が切れたWi2画面で、更新用コードを入力してログインします。ログイン画面は`ログイン画面を開く`から、アプリ専用の独立ウインドウで開けます。
4. インターネットに接続できたら`更新完了`を押します。次の10分の計測と次回コードの取得を開始します。

期限が過ぎても取得済みコードを保持します。未取得で期限を迎えた場合は、インターネットに接続できる回線で`コード取得を再試行`を押してください。

ウインドウを閉じてもメニューバーで動作します。アプリ終了中やMacのスリープ中は取得・通知できません。再起動時は保存済みのコードとログイン時刻を復元し、元の期限に従って再開します。`接続管理を停止`はタイマーと自動取得を停止します。

利用期限の計算は手動で確認したログイン時刻に基づき、Wi2のサーバーから残り時間を取得するものではありません。[対象のゲストログイン画面](https://service.wi2.ne.jp/freewifi/wi2premium_guest/sp/ja/)では初回ログインから10分と案内されています。

## 検証

